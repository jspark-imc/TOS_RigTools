# C:\claude — 리깅 툴 작업 규칙

규칙 버전: **2026-10-28** (바뀐 내용은 맨 아래 '규칙 변경 기록')

이 파일 하나만 규칙이다. 하위 폴더에 CLAUDE.md 를 새로 만들지 않는다.
처음이면 `C:\claude\START_HERE.md`(회사 묶음에만 있음)를 먼저 읽는다. 없으면(집 PC) `C:\claude\max_blender\1_project\지금_상태.md` 부터 읽는다.

## 말하기
- 사용자 대상 설명은 한국어, 짧고 쉬운 말. 코드 식별자는 영문.
- 판단이 서지 않으면 멈추고 무엇이 불분명한지 말하고 묻는다. 추측하지 않는다(대상 오브젝트·파일·본 이름이 애매하면 묻기, 방법이 여럿이면 장단점과 함께 제시).
- 문제가 생기면 바로 짧게 보고한다. 숨기거나 혼자 우회하지 않는다. 오류, 예상보다 나쁜 결과, 예상보다 긴 시간, 판단이 필요한 갈림길은 끝날 때까지 기다리지 말고 그때 알린다.
- 파일을 알려 줄 때는 이름만 말하지 말고 바로 열 수 있게 **전체 경로**(`C:\claude\max_blender\...`)를 적는다.

## 되묻기 규칙
질문이 이해되지 않거나 문장이 너무 길면, 되물을 때 아래 형식으로 정리해서 확인한다.
1. 한 줄에 요청 하나만 쓴다.
2. 순서가 있으면 번호를 붙인다.
3. 조건이 있으면 "없으면 ~"처럼 짧게 붙인다.

## 세션 나누기
- 작업 주제가 바뀌면(지금 대화의 결과·맥락이 필요 없는 새 작업) 진행하기 전에 새 세션으로 나누자고 제안한다. 사용자가 여기서 하겠다고 하면 그대로 진행.
- 큰 작업이 끝났는데 다음 할 일이 길게 남았거나, 대화가 길어져 앞 내용이 요약(압축)된 뒤라면, 남은 일을 정리해(`max_blender\1_project\` 문서) 새 세션으로 넘기자고 제안한다.

## 모델 선택
- 복잡한 설계나 고난이도 작업(많은 함수 계산, 여러 단계 구조 설계 등)이면 시작 전에 작업자(사용자)에게 "오푸스 높음 또는 페이블로 올리는 게 좋다"고 먼저 권유한다.
- 모델은 임의로 바꾸지 않는다. 바꾸거나 더 비싼 설정으로 올리는 것은 작업자가 허락해야 한다.

## 작업 원칙
- 코딩 전에 가정을 말한다. 해석이 여럿이면 선택지를 보인다. 더 단순한 방법이 있으면 말한다.
- 요청한 것만 최소로. 요청 안 한 기능·옵션·추상화 금지. 관계없는 코드·장면·파일은 건드리지 않는다. 고친 범위를 짧게 보고.
- 완료 기준을 먼저 정하고 검증 후 끝났다고 말한다: 리그 = `max_check_rig` ERROR 0, 변형 = Max↔블렌더 정점 비교, 스크립트 = Max/블렌더에서 실제 실행. 검증 못 한 부분은 그렇다고 밝힌다.
- 반복 수정은 사용자가 승인한 범위 안에서만. 범위를 넘으면 먼저 묻는다.

## Max·블렌더 포트 (가장 중요)
- 작업자(사용자) Max = 9877. **Claude 는 9877 Max 에 절대 연결·작업하지 않는다.**
- Claude Max = 9878 (~9899). `max_blender\launch\Max_Claude_lock.bat`(아래 '창 나눠 쓰기') 또는 `Max_Claude_multi.bat` 으로만 켠다(`max_claude_profile\3dsmax_claude.ini` 사용, 작업자 설정을 덮지 않음).
- Max MCP(`max_blender\mcp\max_mcp.py`)는 환경변수 `MAXBRIDGE_PORT`(기본 9878)로 연결. 도구마다 `port` 인자로 예약한 창을 고른다(9878~9899 만, 9877 거부). 블렌더에서는 `max_bridge.send(code, port=9878)` 처럼 포트를 직접 지정(기본값 9877 = 작업자 Max).
- 블렌더: 작업자 블렌더 = 9876, **Claude 는 작업자 블렌더 창에 연결·작업하지 않는다.**

- 리스너·문서에 나오는 "listening on 127.0.0.1:9877" 은 **작업자 Max** 가 정상이라는 뜻이다. Claude 가 붙을 곳은 9878.

## Max 창 나눠 쓰기 (Claude 작업 여러 개)
- Max 를 쓰기 전에 `C:\claude\max_blender\launch\Max_Claude_lock.bat claim -Owner <작업 이름>` 으로 창을 예약하고, 마지막 줄 `PORT=98xx` 만 그 작업 동안 쓴다(MCP 는 `port` 인자, 블렌더·스크립트는 `MAXBRIDGE_PORT`).
- 빈 창이 없으면 새 Claude Max 를 자동으로 켠다(최대 3개). 다 차 있으면 기다리고(`-Wait`) 작업자에게 알린다.
- 내가 예약하지 않은 창에는 아무것도 보내지 않는다.
- 끝나면 저장한 뒤 `release -Owner <이름> -Port <포트>` 로 반납한다(장면이 비워짐). 6시간 넘게 쓰면 `renew`.
- MaxBridge 명령 안에서 `resetMaxFile` 을 실행하지 않는다(브리지가 멈춤. 풀기: 그 Max 리스너에서 `MaxBridge.busy = false`).
- 누가 어느 창을 쓰는지 보기: `Max_Claude_lock.bat` 더블클릭. 잠금 파일 `max_blender\exchange\max_lock\`.
