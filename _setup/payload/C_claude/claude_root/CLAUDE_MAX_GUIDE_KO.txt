Claude Max 환경 안내 (작업자 Max 를 건드리지 않는 규칙)  2026-10-27c
=====================================================================

[두 개의 Max]
  작업자 Max : 평소처럼 켜는 Max. 포트 9877. 작업자 설정(%LOCALAPPDATA%\Autodesk\3dsMax\2014 - 64bit\ENU\3dsmax.ini)
  Claude Max : C:\claude\max_blender\launch\Max_Claude_multi.bat 로만 켬. 포트 9878~9899.
               설정 = C:\claude\max_claude_profile\3dsmax_claude.ini (따로 있음)

[작업자 Max 를 건드리지 않는 것들]
  1. Claude 는 9877(작업자 Max)에 절대 연결·작업하지 않는다. Claude Max(9878~)만 쓴다.
  2. Claude Max 는 자기 설정 파일로 켜서, 단축키·UI·창 크기·최근 파일이 작업자 Max 에 섞이지 않는다.
     (도구 스크립트 폴더는 같이 읽음 -> 작업자 Max 와 같은 도구를 씀)
  3. 포트를 바꿀 때(MBport) Max Bridge 가 막아 준다: 작업자 Max 는 9878~ 로, Claude Max 는 9877 로 못 바꾼다.
  4. 작업자 블렌더(9876) 창도 건드리지 않는다. Claude 블렌더는 9866
     (C:\claude\max_blender\launch\Blender_Claude.bat). 이 bat 이 없는 PC 는 화면 없는 블렌더(blender -b)로.
  5. 원본 .max 는 덮어쓰지 않고 사본으로 작업. 파일은 지우지 않고 C:\claude\max_blender\4_discard\ 로.
  6. 설치기는 작업자 Max 설정(3dsmax.ini)을 바꾸지 않는다. 단 시작 스크립트 폴더가 없는 곳을 가리킬 때만
     원인을 보여 주고 Y/N 로 물은 뒤 고친다(백업함).
  전체 규칙: C:\claude\CLAUDE.md

[Claude Max 켜기]
  C:\claude\max_blender\launch\Max_Claude_multi.bat 더블클릭 -> 몇 개 켤지 입력(Enter = 1)
  리스너(F11)에 "[MaxBridge] ... listening on 127.0.0.1:9878" 이 보이면 정상
  지금 쓰는 포트 보기: Max_Claude_multi.bat list

[Claude Code 연결 (MCP)]
  설치 때 Y 하면 자동 등록. 직접 하려면 터미널에서 (블렌더 파이썬 경로는 PC 에 맞게):
    claude mcp add --scope user max -- "C:\Program Files\Blender Foundation\Blender 5.2\5.2\python\bin\python.exe" "C:\claude\max_blender\mcp\max_mcp.py"
    claude mcp add --scope user blender -- "C:\Program Files\Blender Foundation\Blender 5.2\5.2\python\bin\python.exe" "%USERPROFILE%\blender-mcp-lite\blender_mcp_lite.py"
  블렌더 MCP 는 블렌더 안 애드온 'MCP for Blender'(blender_mcp_addon)가 켜져 있어야 연결돼요.

[확인]
  Claude Max 를 켠 상태에서 설치 폴더의 2_CHECK.bat -> "Claude Max 연결 OK (포트 9878, 작업자 Max 와 분리)"
